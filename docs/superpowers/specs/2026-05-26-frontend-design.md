# 联盟管理中心 · 前端设计规范文档

**日期**：2026-05-26  
**项目**：unionManageCenter  
**前端框架**：UniApp（Vue3 + Vite）  
**主要平台**：H5（PC 浏览器）  
**状态**：已通过视觉评审 ✅

---

## 一、整体设计原则

- **简约现代**：大量留白，减少装饰元素，内容优先
- **数据驱动**：每个页面顶部必须展示核心统计数字（KPI 卡片）
- **实时感**：首页大屏数据动态更新，带动画过渡
- **高效操作**：列表页提供充足筛选条件 + 快捷标签，支持批量操作

---

## 二、主题系统

支持三套主题，右下角浮层按钮随时切换，切换不刷新页面。

| 主题 | 标识 | 风格描述 | 主色 | 背景色 |
|------|------|----------|------|--------|
| A | 深色科技 | 深色底 + 蓝色强调，专业感强 | `#3b82f6` | `#0d1117` |
| B | 纯净浅蓝 | 白底 + 深蓝侧边，简约清爽（默认） | `#1e40af` | `#f0f4f8` |
| C | 渐变紫金 | 白底 + 紫渐变侧边，彩色数字卡片 | `#7c3aed` | `#fafafa` |

主题通过 CSS 变量（`--color-primary`、`--color-bg` 等）全局切换，存储至 `localStorage`。

## 三、页面布局结构

采用 **文字侧边栏 + 可收缩** 布局（方案 B）：

```
┌─────────────────────────────────────────┐
│  Topbar（高度 60px）：面包屑 + 时钟 + 操作按钮 │
├──────────┬──────────────────────────────┤
│          │                              │
│  Sidebar │  Content Area（滚动区）       │
│  220px   │                              │
│  (可折叠  │                              │
│  为 64px) │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

**侧边栏结构**：
- 顶部：Logo + 项目名称
- 中部：`nav-section` 分组菜单，带图标 + 文字 + 角标
- 底部：当前登录用户信息（头像 + 姓名 + 角色）
- 折叠按钮：宽度从 220px 切换到 64px，仅显示图标

**面包屑**：最多三层，格式 `首页 › 模块 › 当前页`

## 五、首页大屏（`/dashboard`）

### 布局（从上到下）

1. **欢迎横幅**（蓝色渐变卡片）
   - 左：标题「数据实时概览」+ 绿色呼吸灯 + 当前日期
   - 右：当前在线人数（3秒自动波动）、今日流水、今日新增

2. **KPI 卡片行**（4列等宽）
   - 注册用户总数 / 活跃联盟数 / 本月订单流水 / 待处理订单
   - 每卡片：标题 + 大数字（进场动画）+ 涨跌趋势 + 迷你 sparkline 走势图

3. **图表行**（2:1 比例）
   - 左：近30日折线图（用户增长 + 流水双线，支持月/季/年切换）
   - 右：联盟类型分布圆环图 + 图例

4. **底部行**（1:1 比例）
   - 左：联盟流水排行 TOP 5（进度条样式）
   - 右：实时动态事件流（带颜色分类圆点 + 时间戳，轮播滚动）

### 动态化要求

| 元素 | 更新频率 | 动画 |
|------|---------|------|
| 时钟 | 每秒 | 无 |
| 在线人数 | 3秒 | 数字滚动 |
| 实时动态列表 | 30秒轮询 | 顶部插入 + 淡出 |
| KPI 数字 | 进场时 | `countUp` 动画（0→目标值，0.8s）|
| 折线图 | 进场时 | 路径绘制动画 |

## 六、列表页通用规范

所有列表页（用户/联盟/订单/财务等）遵循统一结构：

### 6.1 顶部统计栏

5个小型 KPI 卡片横排，每个包含：图标 + 大数字 + 标签 + 趋势。  
统计字段根据各模块定制，但布局和样式保持一致。

### 6.2 筛选面板

**通用字段（所有列表必须包含）：**
- 关键词搜索（支持多字段模糊匹配）
- 状态筛选
- 时间范围（创建时间）

**模块专属字段：**

| 模块 | 专属筛选字段 |
|------|------------|
| 用户管理 | 所属联盟、用户角色、实名认证状态、最后登录时间、注册来源 |
| 联盟管理 | 联盟类型、所在地区、审核状态、成立时间 |
| 订单中心 | 订单类型、支付方式、所属用户、所属联盟、金额范围 |
| 财务结算 | 结算状态、收款账户类型、金额范围、结算周期 |
| 数据报表 | 报表类型、时间维度（日/周/月/年）、对比周期 |

**快捷标签**：3~6个高频场景一键切换（如「今日新增」「待审核」「长期未登录」）

**操作按钮**：查询、重置、导出 Excel、新增（主操作）

### 6.3 数据表格

- 首列多选框，支持跨页全选
- 工具栏：已选条数 + 批量操作 + 刷新/列设置/密度切换
- 支持列排序（点击表头），当前排序列高亮
- 状态列统一使用彩色徽章（绿/黄/红/灰）
- 操作列：详情（蓝）、主操作（绿）、更多（灰）
- 行 hover 背景色变化

### 6.4 分页

- 显示总条数 / 当前页 / 总页数
- 页码按钮（前后翻页 + 页码 + 省略号）
- 跳转输入框
- 每页条数下拉（10 / 20 / 50 / 100）

## 九、组件复用规范

### KpiCard 组件
```
Props: icon, label, value, trend(方向+值), color, sparklineData
```

### FilterPanel 组件
```
Props: fields(筛选字段配置数组), quickTags(快捷标签数组)
Emits: search(params), reset, export
```

### DataTable 组件
```
Props: columns(列配置), data, loading, total, pageSize
Emits: sort, select, pageChange, pageSizeChange
Slots: 操作列 action slot
```
